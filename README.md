# Shape Designer

A browser-based 2D character shape editor. No build step required.

## Features
- Canvas with rectangles, ellipses, triangles, lines, and custom polygons
- Select, move, resize, rotate shapes
- Point editing for polygon vertices
- Fill, outline, stroke width, opacity and position controls
- Layers list, duplicate/delete, undo/redo
- Save project in local browser storage
- PNG export, canvas size and background controls

## Run locally
Open `index.html` in a browser.

## GitHub Pages
This repository includes a Pages deployment workflow. In GitHub, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. Pushes to `main` will then deploy the site.
